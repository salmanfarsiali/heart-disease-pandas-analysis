# Heart Disease Pandas Analysis

## Project Overview

This project focuses on exploratory data analysis (EDA) of a Heart Disease dataset using Python and Pandas. The goal is to explore the dataset, understand its structure, identify missing values, perform data manipulation, and discover meaningful patterns through statistical analysis and visualization.

This project is part of my Machine Learning learning journey, where I am developing practical skills in data analysis and data preprocessing.

## Objectives

- Understand the structure and characteristics of the Heart Disease dataset.
- Perform initial data inspection and exploration.
- Identify and handle missing or duplicate values.
- Apply Pandas operations for data cleaning and manipulation.
- Perform descriptive statistical analysis.
- Explore relationships between different features.
- Generate meaningful insights through data analysis and visualization.

## 📊 Dataset Information

This project uses the **Heart Disease Dataset**, which contains medical attributes related to cardiovascular health. The dataset is used to explore health-related patterns, perform data analysis, and identify potential relationships between different medical features and heart disease.

### 🔗 Dataset Source

The dataset is available on Kaggle:

[Heart Disease Dataset – Kaggle](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset?select=heart.csv)

- **Platform:** Kaggle
- **Dataset Name:** Heart Disease Dataset
- **File Name:** `heart.csv`
- **Local File Path:** `data/heart_disease.csv`

## Analysis Workflow

1. **Data Loading:** Import the dataset using Pandas.
2. **Data Inspection:** Examine rows, columns, data types, and dataset information.
3. **Data Cleaning:** Check for missing values and duplicate records.
4. **Data Manipulation:** Apply filtering, sorting, grouping, and other Pandas operations.
5. **Statistical Analysis:** Calculate descriptive statistics and explore feature distributions.
6. **Data Visualization:** Use Matplotlib and Seaborn to visualize patterns and relationships.
7. **Insights:** Summarize important findings from the analysis.
